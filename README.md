# L'instant Santé

Portail de prévention santé pour la jeunesse : conseils, urgences, encyclopédie, mythes et quiz.

🔗 **Site** : univetx.github.io

## Contenu
- Accueil et dossiers santé (HTA, diabète, santé oculaire)
- Urgences et premiers réflexes
- Encyclopédie (paludisme)
- « On dit Que ? » : mythes et remèdes populaires
- 10 fiches pratiques à demander sur WhatsApp
- Quiz de 20 questions tirées au hasard

## Technologies
HTML, CSS et JavaScript dans un seul fichier `index.html`. Hébergement avec GitHub Pages.

## Avertissement
Contenu informatif de prévention. Il ne remplace pas l'avis d'un médecin. En cas d'urgence, appelle les secours.
